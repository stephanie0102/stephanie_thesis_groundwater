# Scope Transition Note

Amsterdam was the initial local case because it is spatially concentrated and has a dense set of monitoring wells. That made it a practical starting point for developing the transfer-learning setup, checking whether fixed transfer can help local groundwater forecasting, and diagnosing when transfer causes harm.

The Netherlands extension was added to test whether the same framework generalizes to a larger and more heterogeneous target panel. This expansion does not invalidate the Amsterdam motivation. It changes the scientific question from a local urban case study to a broader test of transfer heterogeneity across a national source-compatible well panel.

The final thesis should therefore present Amsterdam as the methodological starting point and the Netherlands as the main empirical evidence. Amsterdam motivates the problem and demonstrates the local proof-of-concept; the Netherlands result carries the final generalizability and transfer-heterogeneity claim.

The active pipeline remains the Netherlands pipeline under `Code/` and `Data/processed/methodology/`. The recovered Amsterdam files under `Data/processed/amsterdam_reference/` are comparison artefacts only.
